# Games (Treinamento / Aprendizado)

Esta pasta guarda **jogos de referência** (prompts + planos + checklist) usados como treinamento/benchmark do pipeline de geração.

## Como usar

1. Escolha um jogo nesta pasta.
2. Copie o conteúdo do arquivo (prompt/brief) para iniciar o fluxo de geração no Studio.
3. Use o **Human Game Plan** como contrato: o jogo só deve ser gerado quando o plano humano estiver claro e validado.
