- Painel de assets

**O que é**: Demonstração do sistema visual
**Features**:
- Hero section com neon-text
- Grid de cards com efeitos
- Paleta de cores neon
- Exemplos de tipografia
- Demonstração de animações

### 3. Components Library (/components) ⭐

**Features**:
- 6 tabs (Forms, Modals, Loading, Data, Feedback, Advanced)
- Todos os componentes em ação
- Código pronto para usar
- Layout com sidebar

```typescript

```

### Criar uma Página
```typescript
import { MainLayout } from "@/components/layout/MainLayout";

export default function MyPage() {
  return (
    <MainLayout>
      <div className="p-8">
        <h1 className="text-4xl font-bold neon-text">Título</h1>
      </div>
    </MainLayout>
  );
}
```
